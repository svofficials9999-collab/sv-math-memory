# Curriculum sources and limits
Read on 14 October 2026.
- NCERT elementary mathematics progression: https://ncert.nic.in/pdf/syllabus/06Math%20(I-V).pdf
- CBSE 2026-27 Class X mathematics: https://cbseacademic.nic.in/web_material/CurriculumMain27/SecPart1/Maths_SecP1X_2026-27.pdf
- Telangana SCERT textbook catalogue: https://scert.telangana.gov.in/e-Textbooks.htm (page says 2022-23; not a current complete exam pattern).
- Telangana Class VII maths textbook: https://scert.telangana.gov.in/pdf/publication/ebooks/7%20mathematics%20em%202024-25.pdf
- Government-hosted NVS 2027-28 prospectus: https://bongaigaon.assam.gov.in/sites/default/files/public_utility/Prospectus%20JNVST%20for%20the%20Session%202027-28.pdf (arithmetic: 20 questions, 25 marks, suggested 30 minutes; arithmetic subsection only, not the full entrance exam).

Questions are original practice, not copied official exam questions. This is a starter bank with class-appropriate progression, not complete curriculum coverage. Upper-class banks include prior-class revision topics. All numeric keys checked deterministically, but teacher and native Telugu review still needed. Olympiad, scholarship and numerical aptitude modules are general practice categories with no claim to a specific official scheme. Current Telangana SSC pattern remains unverified. No official label is used.
